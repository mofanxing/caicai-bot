# 菜菜 Bot 前端

React + TypeScript + Vite + Ant Design 实现的本地管理台，方便直接在浏览器测试后端，不需要 Postman。

## 启动

需要 Node.js 20.19+ 或 22.12+，以及已配置的后端环境。

终端一，在项目根目录执行：

    cd backend
    source .venv/bin/activate
    uvicorn app.main:create_app --factory --reload

终端二，在项目根目录执行：

    cd frontend
    npm ci
    npm run dev

浏览器打开 http://127.0.0.1:5173 。首次进入时，打开 backend/.env，复制 ADMIN_TOKEN 等号后面的值，粘贴到页面并连接。不需要填写 Bearer 前缀。

后端依赖未安装时，先按根目录 README 配置 Python 环境。安装过前端依赖后无需每次运行 npm ci。

## 使用

1. 连接后端，点击“创建第一个会话”，输入名称。
2. 如果后端开启 MOCK_LLM_ENABLED，可直接发送消息验证模拟回复。模拟回复带有明确前缀，不是真实 AI。
3. 在“中转站管理”里添加名称、Base URL 和真实 API Key，密钥输入默认隐藏。
4. 保存后立即生效，无需修改 .env 或重启。页面仅显示“密钥已加密保存”；通过“替换密钥”可以更新，不能查看原值。
5. 点击“测试连接 · 获取模型”。失败时检查地址、密钥和站点兼容性。
6. 回到聊天测试，右侧选择站点，点击“获取列表”，选择或手动输入模型 ID，并选择已添加的朗读音色，再保存设置；没有音色时需先到“音色与语音”上传参考录音。
7. 在底部输入框发送消息。Enter 发送，Shift + Enter 换行。

各会话有独立的站点、模型、角色设定和聊天记录。修改设置后需点击保存；发送时使用已保存的配置。消息失败或超时后可以刷新记录，页面不会自动重复发送。

每轮消息下方可删除该轮对话。聊天右上角“更多”可清空记录或删除测试会话，均需确认。删除会移除后续聊天所用的对应上下文。中转站卡片支持删除；关联会话保留记录并解除模型绑定。

API Key 只在保存时提交，后端加密存储，页面不回读密钥，不写入浏览器存储。主密钥管理及部署安全说明见根目录 README。管理令牌暂存在当前标签页的 sessionStorage。点击“连接设置 → 断开并清除令牌”清除。前端环境变量中不存放管理令牌或 API Key。

## 本地语音

进入“音色与语音”上传参考录音（3～30 秒 WAV/MP3）并生成试听；聊天设置必须选择朗读音色后才能保存，保存时固定使用文字与语音同步生成，旧纯文字会话也会切换。聊天设置不再显示“回复方式”和“语音表达提示词”，已有表达提示词继续保留；当前本地复刻模式的语气跟随参考录音，自由文本语气指令暂不参与合成。开启顶部“自动朗读”后按段播放，也可手动朗读。音频失败保留文字，可单独重试。首次需准备 Mac 本地环境，详见 [本地语音文档](../docs/LOCAL_TTS.md)。

打开旧会话时，已有语音的消息显示「开始朗读」。点击后才查询该条语音的分段状态、下载并解码音频。开启自动朗读后，新回复会预取当前段和后续最多两段，以便连续播放。

“思考与等待语音”仍可按会话开关并编辑两条短句。选择音色后点击“保存并生成提示语音”，先保存当前设置，再替换上一版提示语音；仅保存聊天设置不会合成提示语音。播放提示需同时开启“等待时语音回应”和顶部“自动朗读”。

## 范围

- 已对接：站点创建、查询、删除，API Key 配置与替换、模型列表、会话创建和选择、模型与角色设置、聊天发送、历史记录以及记录/会话删除。
- 已对接语音：音色上传/删除、原音与合成试听、聊天音频和失败重试，以及按会话手动生成思考 / 等待提示语音；表达指令字段保留兼容，当前本地复刻模式暂不使用。
- 未提供：站点名称/地址原地编辑、微信登录、语音输入。待接入能力在页面中明确标记并禁用。
- 本页面是开发测试工具，聊天发送依赖后端 debug 接口。APP_ENV=production 时该接口关闭，不应当成生产聊天客户端部署。

## 语音聊天与唤醒词

聊天输入框上方点击「语音设置」修改默认唤醒词「菜菜」，再点击「开始语音聊天」并允许麦克风。说「菜菜，介绍一下你自己」，停顿约 0.9 秒后自动识别和发送；也可先单独唤醒，再说问题。支持中文同音匹配，关闭唤醒词后每段说话直接发送。设置保存在当前浏览器，刷新后需重新开始监听。

识别使用 Apple Silicon Mac 本地 Whisper-small。在项目根目录执行 `backend/.venv/bin/python backend/local_asr/setup.py` 安装模型，复用现有隔离 MLX 环境。浏览器需要 localhost / HTTPS 和 AudioWorklet；默认 Vite 本机地址可用。选择并保存会话音色后，回答沿用该音色，开始语音聊天会开启自动朗读。

每段最长 20 秒；处理请求和播放回答 / 提示语时暂停识别，不支持播放中唤醒打断。结束、切换会话 / 页面或断开连接释放麦克风。录音仅在内存中送往本机识别；识别后的提问仍按会话配置调用模型。安装、接口及排错见 [语音聊天说明](../docs/VOICE_CHAT.md)。

## 开发与验证

    npm run test
    npm run build
    npm run preview

Vite 开发服务器以及 preview 把 /api 和 /health 转发至 http://127.0.0.1:8000。默认只监听本机，无需修改后端 CORS。变更后端端口时编辑 vite.config.ts 中的代理地址并重启前端。

也可以通过 CAICAI_API_TARGET 环境变量临时指定代理目标，便于使用隔离测试后端，例如 CAICAI_API_TARGET=http://127.0.0.1:8001 npm run dev。

dist 是静态构建产物。将来部署到独立 Web 服务器时，需要配置 /api 的反向代理，不能仅双击 dist/index.html。当前 Docker Compose 仅包含后端。
