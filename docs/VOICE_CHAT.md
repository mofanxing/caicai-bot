# 本地语音聊天与唤醒词

更新与验收日期：2026-11-20（Asia/Shanghai）。

桌面与网页聊天使用同一套输入：麦克风 → 本机 Whisper-small 中文识别 → 唤醒词匹配 → 当前会话流式聊天 → 既有音色与分段朗读。

## 使用

1. 选择聊天会话，配置模型与回复音色并保存。
2. 输入框上方点击「语音设置」，修改唤醒词；默认「菜菜」。设置保存在当前设备，桌面与浏览器各自独立。
3. 点击「开始语音聊天」并允许麦克风。启动后会开启自动朗读。
4. 说「菜菜，告诉我现在几点」，停顿约 0.9 秒自动识别并发送；也可只说「菜菜」，等显示「已唤醒」后，在 12 秒内说问题。每轮重新唤醒；关闭「启用唤醒词」后，每段说话直接发送。
5. 点击「结束语音聊天」释放麦克风。切换页面、会话或断开后端也会停止；收起桌面窗口保留已开启的监听，刷新或重启后需手动开始。

唤醒词需要 2～24 个有效字符。匹配忽略标点、空格、英文大小写和全半角；纯中文还按完整音节匹配，支持「菜菜 / 蔡蔡 / 采采」等 ASR 同音结果。修改设置会停止当前监听，重新开始后生效。

每段最长 20 秒。文字请求、语音缓冲、回答、等待提示语及任务播报期间暂停识别，结束后留出 450 毫秒避免扬声器尾音进入下一段。不支持在回答播放时用唤醒词打断。语音发送保留输入框中尚未发送的文字草稿。

## 安装

当前引擎使用 Apple Silicon Mac 的 MLX。在项目根目录执行：

```sh
backend/.venv/bin/python backend/local_asr/setup.py
```

复用现有 `backend/.tts-venv`（mlx-audio 0.6.5），缺少环境时调用既有语音安装脚本准备。首次下载约 0.5 GB 的多语言 Whisper-small 权重和分词器；模型固定为 `mlx-community/whisper-small-asr-fp16` 的提交 `42fc41c2ab1c78e844fd01477cf398eec6801c47`，保存在 `backend/data/asr/models/Whisper-small/`，不提交 Git。

代码升级后重启后端，桌面端需 `cd desktop && npm run build` 后重新启动。只安装模型不需重启已有新版后端，点击开始即可重新检查。

配置项：`LOCAL_ASR_PYTHON`、`LOCAL_ASR_MODEL_DIR`、`LOCAL_ASR_TIMEOUT_SECONDS`（默认与上限均为 60 秒）。安装脚本读取前两个环境变量；使用自定义路径时，将同一配置传给脚本与后端。默认路径均在项目内。

浏览器需要 localhost / HTTPS、安全上下文、AudioWorklet 和麦克风权限。macOS 拒绝时，在「系统设置 → 隐私与安全性 → 麦克风」允许浏览器或 Electron。桌面权限仅开放给本机聊天窗口的音频采集，不开放摄像头。

## 数据与行为

- 开始后持续采集，在前端按音量检测说话起止，只将有人声的分段提交本机后端。唤醒词基于 ASR 文本匹配，属于持续识别方案。
- 录音仅在内存传输和识别，不写入音色库、不保存文件、不调用云端 ASR。工作进程强制离线，在多段间复用已加载模型，退出后端时清理。
- 只有唤醒后的提问进入聊天记录。真实中转站会接收识别后的提问，与正常文字聊天相同。
- 静音和不足 200 毫秒的脉冲不提交；同一识别器只处理一个请求。失败显示错误并停止监听，不自动重发问题；停止、切换或被播放打断的过期识别不会稍后补发。
- 未选音色可语音提问并得到文字回答；要语音回答，先保存音色。现有 VoxCPM2 的首次加载及合成速度限制仍适用。

## 接口与验证

管理鉴权沿用 `Authorization: Bearer <ADMIN_TOKEN>`，桌面代理继续校验已有能力令牌。

- `GET /api/v1/speech/recognition/status`：环境、模型及运行状态。
- `POST /api/v1/speech/transcriptions`：multipart 字段 `audio`；0.2～20 秒、16 kHz、单声道 PCM16 WAV。返回 `text`、`language`、`duration_seconds`、`recognition_seconds`，只转写，不创建会话或发送消息。

测试覆盖音频校验、鉴权、并发保护、进程复用与清理、VAD、重采样、唤醒词与同音匹配、唤醒后语句排队、播放暂停、过期结果和设置持久化。

```sh
cd frontend && npm test && npm run build
cd ../backend && .venv/bin/pytest tests -q && .venv/bin/ruff check app local_asr
cd ../desktop && npm test && npm run smoke:voice && npm run smoke:chat
```

`smoke:voice` 使用临时数据库、真实 Electron、系统合成的中文 WAV 虚拟麦克风、真实 AudioWorklet 和本地 Whisper，验证识别后通过正式桌面通道只发送一轮，唤醒词剥离、自定义设置持久化、结束后释放轨道和拒绝摄像头。聊天模型和回复音频使用既有静音夹具，不访问真实麦克风、不修改已有会话。报告与截图在 `desktop/.data/voice-chat-smoke.json` / `voice-chat-smoke.png`；需要已安装本地 ASR 和 macOS Tingting 系统语音。
