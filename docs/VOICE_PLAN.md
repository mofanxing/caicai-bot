# 音色复刻与聊天播报方案（M0）

更新：2026-11-16。已实现本地语音闭环并通过真实模型接口与浏览器播放验证。安装、操作、API、限制和实测见 [本地语音使用说明](LOCAL_TTS.md)。

## 已确定方案

用户选择本地模型，不接入付费云端 TTS。采用 MLX-Audio 0.6.5 + VoxCPM2-4bit，在 Apple M1 Pro / 32 GiB 上运行；独立 Python 环境和持久 worker 隔离依赖。首次安装下载约 2.3 GB 模型，推理离线。聊天模型继续沿用中转站配置。

上传 3～30 秒参考录音，将音频作为合成条件，无需训练。默认语气和每次试听语气支持自由文本。聊天角色提示词控制回复内容，独立语音表达提示词控制说话方式。参考音频与表达指令同时传给 VoxCPM2。

## 验收与后续

已使用官方示例跑通“参考录音 → 新文字试听 → 聊天音频 → 鉴权播放 → 去重 → 删除清理”。预热后短句合成约 3～5 秒；首次模型加载和编译明显更慢。速度和声音效果依录音、文本与负载变化，不保证完全还原声音或精确执行任意情绪描述。

2026-11-18 已移除 600 字符上限：聊天全文按最多 120 字符分段合成，首段就绪即播。推理保持单并发，同一回复分段共享队列容量，其他独立任务保持 8 个活动任务的准入限制。语音失败不会重新调用聊天模型。

下一步用目标录音试听调整，然后进入 [路线图](ROADMAP.md) M1 桌宠；ASR、持续监听、实时打断和微信继续后置。
