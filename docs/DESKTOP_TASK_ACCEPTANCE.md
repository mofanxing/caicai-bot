## 自动汇报约束

开始、编辑结果、启动检查、异常四类节点各最多一次，至少间隔30秒；快进展合并，过期或任务已结束的进展不补播。模型摘要在独立线程与短超时客户端中执行，不占聊天或 worker 存储锁；模型失败回退结构化事实，任务执行不受影响。正常聊天语音优先，通知遵循自动朗读设置。

定向测试覆盖并发去重、重启去重、限频、仅结构化事件触发、摘要期间并行聊天和 worker 记录、结束后迟到摘要丢弃、模型失败回退、过期语音清理、无音色保留文字、暂停后丢弃旧进展，以及合成前跳过失效进展。
